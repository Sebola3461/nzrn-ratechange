# nzrn-ratechange
It does the same thing as osu-trainer but without install anything!

## How to use
1. /np a map in [my dm](https://osu.ppy.sh/home/messages/users/15821708)
2. Use !ratechange
  - - You can use !ratechange 1.2x or !ratechange 200bpm (example) to change speed rate using bpm or multiplier
  - - For osu!standard beatmaps, you can use the -noscalear or -noscaleod to ignore OD or AR values multiplier too
  - - Example using flags: !ratechange 1.2x -noscalear (beatmap's AR stays at the same) | !ratechange 1.5x -noscaleod (beatmap's OD stays at the same)
   
3. The bot will send you a download link. Just download and open the osz file.
